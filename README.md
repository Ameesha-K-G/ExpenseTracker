# 🪙 Sookshich__chelavakkane (സൂക്ഷിച്ചു ചെലവാക്കണേ!)

A lightweight, premium web application built with HTML, CSS, and Vanilla JavaScript to track your daily income and expenses. Formatted natively in Indian Rupees (₹), it features an elegant **"Emerald Wealth"** theme layered over a professional financial desktop background.

## ✨ Features

* **📊 Live Balance Dashboard:** Real-time calculation of your total current balance, total income, and total expenses.
* **🟢 Visual Transaction History:** Color-coded transaction rows (soft green for Income, soft red for Expenses) with perfectly aligned amounts on the right edge.
* **💾 Local Storage Support:** Your data is saved automatically in the browser, so it stays safe even if you refresh or close the tab.
* **🧹 Interactive UI:** Modern look using filled Google Material Icons and smooth hover-to-delete animations.

## 📁 Project Structure

* `index.html` – Structure and layout.
* `style.css` – "Emerald Wealth" theme styling and background integration.
* `script.js` – Form handling, balance calculations, and local storage logic.

## 🚀 How to Run

1. Clone or download the repository.
2. Make sure the background image (`top-view-finance-business-elements.jpg`) is placed in the same project directory.
3. Open `index.html` in any modern web browser!
